El Faro de las Letras

Proyecto de una librería web desarrollado con HTML, CSS y JavaScript.

Funcionalidades:

- Agregar libros al catálogo.
- Mostrar título, imagen, precio y género.
- Carrito de compras.
- Contador de productos en el carrito.
- Diseño web responsivo.

Tecnologías utilizadas:

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
